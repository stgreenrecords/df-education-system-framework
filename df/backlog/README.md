# Backlog

This folder is the tracker-neutral backlog source for the Education System Framework initiative.

The backlog is designed to be managed first as Markdown inside the Dark Factory Framework, then synced or manually imported into Jira, GitHub Issues, Linear, YouTrack, or another issue tracker.

## Backlog hierarchy

```text
Roadmap
→ Epic
→ Feature
→ User Story
→ Task / Subtask
→ Bug
→ Technical Debt
→ Research Spike
```

## Required fields for issue-tracker import

Each backlog item should include:

- Type
- ID
- Title
- Description
- Owner role: PO / SA / Dev / QA
- Priority
- Phase
- Dependencies
- Acceptance criteria
- Open questions
- Status

## Current scope

The initial backlog focuses on converting the product idea into:

- Product vision
- Domain model
- Architecture direction
- MVP definition
- Roadmap
- Initial epics
- Initial user stories
- Acceptance criteria
- Solution Architect questions
- PO refinement questions
