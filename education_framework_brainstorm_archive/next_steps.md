# Recommended Next Steps

## 1. Start Dark Factory workflow

Use the project framework to create the first product task:

Task:
Define product vision, domain boundaries, MVP scope, and architecture assumptions for the Sovereign Education Platform Framework.

Suggested roles:
- Product Owner: product goals, MVP scope, user personas
- Solution Architect: architecture, update model, security, deployment
- Developer: domain model and technical feasibility
- QA: acceptance criteria, risks, test strategy

## 2. Create core documents

Recommended first documents:
- Product Vision
- Domain Model
- Configuration & Inheritance Model
- Institution Schema Packs
- Meal & Catering Module
- AI Assistance Policy
- Security & Sovereignty Requirements
- MVP Scope
- Poland Country Template Research Plan

## 3. Define MVP Boundary

Recommended MVP:
- Poland reference configuration
- school schema implemented first
- kindergarten and university schemas designed initially
- meal/catering v1
- attendance
- gradebook
- homework
- AI student helper
- AI teacher helper
- dashboards v1
- release/update manager concept

## 4. Research Poland

Research using public/open sources:
- official education structure
- school types
- grading system
- subjects
- school year/semester structure
- exams
- administrative levels
- language requirements
- privacy/legal constraints

Do not hardcode Poland into core. Use Poland only as first country template.

## 5. Solution Architect Tasks

Prepare:
- target architecture
- module boundaries
- API-first approach
- Java Spring/PostgreSQL recommendation
- security model
- deployment model for sovereign self-hosted countries
- update package and compatibility checker design
- data model strategy
- audit strategy
- integration strategy
